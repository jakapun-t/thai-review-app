# Thai review word counter (Streamlit)

ตัวนับคำรีวิวภาษาไทย / A word counter for Thai reviews.

- `nlp_logic.py`: ส่วนประมวลผล (processing): `analyze_text()` and the sample reviews `SAMPLE`
- `app.py`: ส่วนหน้าตา (interface), made with Streamlit
- `requirements.txt`: libraries to install

## Run / วิธีรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

The app opens at http://localhost:8501 / แอปจะเปิดที่ http://localhost:8501
